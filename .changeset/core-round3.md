A self-signed https dev server passes the `webServer` readiness check. `--record` refuses a non-2xx status or a non-JSON body before writing, and leaves the existing replay file. `SNAPSEQ_RECORD` takes `1`/`true` or `0`/`false`/empty and rejects anything else. `host` must be an http(s) URL. The final terminal summary lists only the rows that ran, were skipped or were interrupted; the footer still counts every row. `metadata.snapseq` is restored after an override brings its own `metadata`. `--ui`, `--ui-host` and `--ui-port` get the list reporter, like `--list` and `--debug`. The CLI runs the Playwright installed beside the config, so `snapseq -c apps/web/snapseq.config.ts` works from a monorepo root.
